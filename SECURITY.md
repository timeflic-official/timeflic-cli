# Security

Please report security problems privately: open the **Security** tab of this repository and choose **Report a vulnerability**. Don't open a public issue for them.

This covers the TimeFlic CLI (`@timeflic/cli`). If you find a problem in TimeFlic itself, you can report it the same way and it will be passed to the right team.

Releases are built only by this repository's `release` workflow and published with npm provenance; a version of `@timeflic/cli` without provenance from `timeflic-official/timeflic-cli` (apart from 0.1.0) did not come from us.
